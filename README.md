# cursus website

Marketing-Website für cursus: KI-Disposition, die für jeden LKW die beste nächste Ladung rankt.
React + TypeScript, gebaut mit esbuild, Deutsch und Englisch.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/
```

Alles Weitere (Struktur, Inhaltsregeln, Design-System, offene Punkte) steht in [CLAUDE.md](CLAUDE.md).

Kartendaten: Natural Earth 1:50m (Public Domain). Alle Ladungen, Routen und Simulationen sind Beispieldaten.
